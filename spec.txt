  ロボットアーム・コンフィギュレータ 仕様書 v0.1                                                                                                                           
                                                                                                                                                                           
  0. このドキュメントの読み手へ
                                                                                                                                                                           
  あなたは新しい Web アプリ「ロボットアーム・コンフィギュレータ」の開発を任されています。これは既存の Scratch 拡張プロジェクト xcx-g2s                                     
  （https://github.com/tfabworks/xcx-g2s）の周辺ツールとして、教育用ロボットアームを設計 → 3D プリント → 組立 → Scratch 
  から制御するワークフローを成立させるためのものです。                                                                                                                     
                  
  xcx-g2s は akadako 基板（Firmata 系プロトコル）を介して LED・サーボ・各種センサを Scratch から扱う拡張で、サーボは現状 SERVO1（A1=pin10）/ SERVO2（A2=pin11）の 2        
  軸が直接制御可能です。多軸アームに拡張するための「設計入口」を本ツールが担います。
                                                                                                                                                                           
  ---             
  1. 背景と目的
               
  1.1 解決したい問題
                                                                                                                                                                           
  - 学校環境でブラウザ完結のロボットアーム設計手段が無い                                                                                                                   
  - Tinkercad は形状しか作れず、関節情報（URDF）を持たない                                                                                                                 
  - Fusion360 / Onshape は CAD 学習コストが高く、子供向けには重い                                                                                                          
  - 既存の URDF 生成ツールは ROS 前提で教育機関向けではない                                                                                                                
                                                                                                                                                                           
  1.2 提供価値                                                                                                                                                             
                                                                                                                                                                           
  - CAD 未経験の中高生でもロボットアームを設計できる                                                                                                                       
  - 出力した URDF + STL がそのまま xcx-g2s で制御でき、3Dプリンタで印刷できる
  - インストール不要、サーバ不要、ブラウザだけで完結                                                                                                                       
                                                                                                                                                                           
  1.3 ターゲットユーザ                                                                                                                                                     
                                                                                                                                                                           
  - 中学生〜高校生（小学校高学年も視野）                                                                                                                                   
  - 教員（指導者・環境準備）
  - 動作環境：学校の Chromebook / iPad / Windows PC（モダンブラウザ）

  2. スコープ                                                                                                                                                              
                  
  2.1 やること（IN SCOPE）

  ┌──────────────────┬─────────────────────────────────────────────┐                                                                                                       
  │       機能       │                    内容                     │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ テンプレート選択 │ 4軸 / 5軸 / 6軸 / グリッパー付き            │
  ├──────────────────┼─────────────────────────────────────────────┤
  │ リンク寸法編集   │ 長さ・太さ・形状（角柱/円柱）をスライダ調整 │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ サーボ選択       │ 限定リスト（SG90/MG90S/MG996R 等）から選ぶ  │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ 関節設定         │ 軸方向・可動範囲・ホーム位置                │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ 3Dプレビュー     │ リアルタイム表示 + 関節アニメーション       │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ 検証             │ トルク計算・電源見積・干渉チェック          │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ 出力             │ URDF 1.0 + リンク別 STL                     │
  ├──────────────────┼─────────────────────────────────────────────┤                                                                                                       
  │ xcx-g2s 連携     │ ファイル出力経由（疎結合）                  │
  └──────────────────┴─────────────────────────────────────────────┘                                                                                                       
   
  2.2 やらないこと（OUT OF SCOPE）                                                                                                                                         
                  
  - 汎用 CAD（Tinkercad/Fusion360 の代替ではない）                                                                                                                         
  - フリーフォーム造形（NURBS、スカルプト、ブール演算等）
  - ロボットアーム以外（車両・ヒューマノイド・ドローン等）                                                                                                                 
  - リニア機構・ベルト駆動・ギア比設計                                                                                                                                     
  - 動作プログラミング（xcx-g2s 側の責務）                                                                                                                                 
  - 動力学シミュレーション（重力下での動作再現等）                                                                                                                         
  - 逆運動学（IK） — 必要なら xcx-g2s 側で実装                                                                                                                             
  - アカウント／クラウド保存 — 学校 IT 制約のため                                                                                                                          
                                                                                                                                                                           
  2.3 非ゴール                                                                                                                                                             
                                                                                                                                                                           
  - フル機能 CAD への成長                                                                                                                                                  
  - マルチユーザ協調編集
  - バージョン管理

  3. 機能要件
                                                                                                                                                                           
  3.1 テンプレート選択画面
                                                                                                                                                                           
  - 起動時に「新規（テンプレート選択）」「既存ファイルを開く」                                                                                                             
  - テンプレート例：4軸+グリッパー / 5軸 / 6軸
  - テンプレートは内部で標準のアーム定義 JSON として保持                                                                                                                   
                                                                                                                                                                           
  3.2 メイン編集画面                                                                                                                                                       
                                                                                                                                                                           
  - 左：階層ツリー（リンク・関節・サーボ）                                                                                                                                 
  - 中央：3D プレビュー（three.js）
  - 右：選択中要素のプロパティパネル（スライダ中心）                                                                                                                       
  - 上部：ツールバー（保存・出力・元に戻す/やり直し）                                                                                                                      
  - 下部：検証結果（警告・エラーリスト）                                                                                                                                   
                                                                                                                                                                           
  3.3 リンク編集                                                                                                                                                           
                                                                                                                                                                           
  - 形状：角柱 / 円柱（最初はこの2種のみ）                                                                                                                                 
  - パラメータ：長さ（mm）、断面寸法（幅×高さ または直径）
  - 親リンクからのオフセット                                                                                                                                               
  - 色（任意、可視性のため）                                                                                                                                               
                                                                                                                                                                           
  3.4 サーボ選択                                                                                                                                                           
                  
  - 内部にサーボ DBを持つ（JSON）                                                                                                                                          
    - 機種名、寸法、ホーン形状、最大トルク、ストール電流、動作電圧
    - 取付穴位置（リンクへの埋め込み形状）                                                                                                                                 
  - サーボを選択するとリンクに取付穴と回転軸が自動配置                                                                                                                     
  - 初期対応機種：SG90 / MG90S / MG996R / DS3218                                                                                                                           
                                                                                                                                                                           
  3.5 関節設定                                                                                                                                                             
                                                                                                                                                                           
  - 軸方向：X / Y / Z（親リンク座標系）                                                                                                                                    
  - 可動範囲：min/max 角度
  - ホーム位置：起動時の角度                                                                                                                                               
  - joint type は最初は revolute のみ                                                                                                                                      
                                                                                                                                                                           
  3.6 3D プレビュー                                                                                                                                                        
                                                                                                                                                                           
  - 視点操作（回転・ズーム・パン）                                                                                                                                         
  - 関節をスライダで動かしてアニメーション確認
  - 干渉部位を赤色ハイライト                                                                                                                                               
  - グリッド・床・サイズ参照表示                                                                                                                                           
                                                                                                                                                                           
  3.7 検証機能                                                                                                                                                             
                                                                                                                                                                           
  トルク計算      
  - 下流リンク + サーボの重量を積算
  - 重心位置からのモーメントアームを算出                                                                                                                                   
  - 各サーボの最大トルクと比較し、不足を警告
                                                                                                                                                                           
  電源見積                                                                                                                                                                 
  - 全サーボのストール電流合計                                                                                                                                             
  - USB 給電上限（500mA）超えなら「外部電源必要」警告                                                                                                                      
                  
  干渉チェック                                                                                                                                                             
  - 全関節を可動範囲全体で動かしながら、リンク同士の AABB / メッシュ交差を判定
  - 干渉が発生する角度を提示                                                                                                                                               
                  
  3.8 出力                                                                                                                                                                 
                  
  URDF 1.0                                                                                                                                                                 
  - <robot>, <link>, <joint> を出力
  - 各 link に <visual> <collision> <inertial> を最低限含める                                                                                                              
  - <mesh filename="package://..." /> で同梱 STL を相対参照  
  - 単位はメートル（URDF 標準）                                                                                                                                            
                                                                                                                                                                           
  STL                                                                                                                                                                      
  - リンクごとに 1 ファイル                                                                                                                                                
  - バイナリ STL                                                                                                                                                           
  - サーボ軸穴に +0.2mm の公差を自動付与
  - ZIP にまとめてダウンロード                                                                                                                                             
                                                                                                                                                                           
  アーム定義 JSON（再編集用、独自フォーマット）                                                                                                                            
                                                                                                                                                                           
  3.9 xcx-g2s 連携                                                                                                                                                         
                                                                                                                                                                           
  - 連携方式：ファイル出力経由（最も疎結合）                                                                                                                               
  - 出力した URDF/STL/JSON を xcx-g2s 側で読み込む API を別途定義
  - iframe メッセージングは将来検討

  5. 技術要件
                                                                                                                                                                           
  5.1 推奨技術スタック
                                                                                                                                                                           
  - 3D: three.js  
  - フレームワーク: React + TypeScript
  - 状態管理: Zustand（軽量）or Redux Toolkit                                                                                                                              
  - UI コンポーネント: shadcn/ui or MUI                                                                                                                                    
  - メッシュ生成: three.js のジオメトリ + 自前ブール演算（または manifold-3d / three-bvh-csg）                                                                             
  - STL エクスポート: three.js STLExporter                                                                                                                                 
  - URDF 出力: 自前テンプレート（XML 文字列生成）                                                                                                                          
  - ZIP: jszip                                                                                                                                                             
                                                                                                                                                                           
  5.2 ブラウザ要件                                                                                                                                                         
                                                                                                                                                                           
  - Chrome / Edge / Safari の最新 2 バージョン                                                                                                                             
  - WebGL 2 必須
  - Chromebook での動作必須（メモリ 4GB 想定）                                                                                                                             
                                                                                                                                                                           
  5.3 パフォーマンス目標                                                                                                                                                   
                                                                                                                                                                           
  - 中スペック Chromebook で 60fps プレビュー                                                                                                                              
  - STL 出力 5 秒以内
  - 初回ロード 3 秒以内（gzip 後 2MB 以下）
                                                                                                                                                                           
  5.4 データ永続化
                                                                                                                                                                           
  - ブラウザ LocalStorage（自動保存）                                                                                                                                      
  - JSON ファイルのエクスポート/インポート
  - サーバ不要（学校 IT 制約）                                                                                                                                             
                                                                                                                                                                           
  5.5 配布
                                                                                                                                                                           
  - 静的サイトとしてホスティング（Surge / GitHub Pages / Netlify）                                                                                                         
  - xcx-g2s 本体と同じドメイン下でも、別ドメインでも可
                                                                                                                                                                           
  ---             
  6. UX 要件                                                                                                                                                               
                                                                                                                                                                           
  - 起動から最初の URDF/STL ダウンロードまで 5 分以内を目標
  - 数値入力よりスライダ優先                                                                                                                                               
  - 変更は即時 3D に反映                                                                                                                                                   
  - Undo / Redo 必須（編集系全般）
  - 自動保存（LocalStorage）                                                                                                                                               
  - チュートリアル動線（初回起動時にガイド）
  - 日本語必須、英語は将来対応

  9. リスクと留意事項
                                                                                                                                                                           
  - パラメトリック生成メッシュの 3D プリント適性：肉厚下限・サポート不要向き・公差を自動で担保する設計が必要
  - Chromebook の WebGL 性能：低スペック端末で動くポリゴン数の上限を初期に決める                                                                                           
  - iPad Safari の制約：File System API、ZIP ダウンロードの挙動を要検証                                                                                                    
  - サーボ DB の保守：機種追加時のデータ整備フローを作っておく                                                                                                             
  - URDF の互換性：ROS 1.0 形式準拠だが、<inertial> の値は概算でも実害なし

  10. xcx-g2s 連携の詳細                                                                                                                                                   
                        
  10.1 xcx-g2s の現状（2026-04 時点）
                                                                                                                                                                           
  - リポジトリ: github.com/tfabworks/xcx-g2s                                                                                                                               
  - ブロック実装: src/vm/extensions/block/index.js                                                                                                                         
  - サーボ制御: servoTurn ブロック、SERVO1（pin10）/SERVO2（pin11）                                                                                                        
  - AI 順次処理ブロック：LED= SERVO=angle[,speed] SERVO1= SERVO2= SLEEP= #コメント を解釈                                                                                  
  - xcx-g2s 側の最新は別途 git log で確認すること                                                                                                                          
                                                                                                                                                                           
  10.2 連携の責務分離                                                                                                                                                      
                                                                                                                                                                           
  - 本ツール：アームの形と関節定義（URDF + STL）を出力                                                                                                                     
  - xcx-g2s：URDF を読み込んでScratch ブロック化（多軸サーボ、ポーズ、ティーチング等）
  - → xcx-g2s 側の URDF 受け入れ機能は本ツールと並行して別タスクで開発                                                                                                     
                                                                                                                                                                           
  10.3 出力ファイル一式                                                                                                                                                    
                                                                                                                                                                           
  ZIP に以下を含める：                                                                                                                                                     
  myarm.zip
  ├── myarm.urdf                                                                                                                                                           
  ├── myarm.json         (再編集用)
  ├── meshes/                      
  │   ├── base.stl                                                                                                                                                         
  │   ├── shoulder.stl
  │   └── ...                                                                                                                                                              
  └── README.txt          (組立メモ・サーボピン割当)
